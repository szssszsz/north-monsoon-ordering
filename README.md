# 北境季风 · 独立订餐网站

不依赖 ChatGPT / OpenAI 域名、账号或接口。访客无需登录，可选餐、预约、下单、凭码查询及取消；管理员凭独立口令查看全部订单。订单保存在 PostgreSQL。

## 发布

1. 把本目录推送至可由 Render 读取的 GitHub / GitLab / Bitbucket 仓库。可使用私有仓库。
2. 在用户确认的 Render 工作区中导入 `render.yaml`，或依据同等配置新建 Web 服务与 PostgreSQL。
3. 两项资源都显式选择免费方案，区域均为 Singapore。不得自动改为付费。
4. `DATABASE_URL` 通过数据库引用注入。`ADMIN_PASSWORD` 由 Render 生成，请仅在 Render 的环境变量设置中查看或更换；不要写入仓库。
5. 部署到终态后，检查 `/healthz`，并使用 `test/verify-orders.py` 对真实服务进行校验。记录产生的测试订单，并在校验后取消。
6. 完成中国大陆网络访问验证后，把最终正式地址转换为真实二维码并替换海报。网址必须使用中性名称，不包含用户姓名。

**免费方案限制：** Render 官方文档说明，免费 Web 服务闲置 15 分钟会休眠，重新打开可能需要约一分钟；免费 PostgreSQL 创建 30 天后到期，此后 14 天宽限期结束仍未升级会删除数据。免费数据库没有备份能力。正式长期使用需另行确定持久存储方案，不能把免费数据库说成永久可用。详见 https://render.com/docs/free 。

## 本地

Node.js 24，以及一套可用的 PostgreSQL。

```sh
npm ci --include=dev
npm run check
npm test
npm run build
```

把 `.env.example` 中的变量配置为本地环境变量后运行：

```sh
npm start
```

默认端口 `10000`，监听 `0.0.0.0`。服务端启动时执行幂等建表；已有订单不会被覆盖。

## 管理员

网站底部“订单管理”链接通向 `/admin`。输入至少 16 字符的 `ADMIN_PASSWORD`；登录 Cookie 为 HttpOnly，仅管理员接口可用，有效期四小时。管理员口令不发送给访客，不依赖任何第三方账号登录。

## 安全与数据

- 顾客只需填写称呼，不采集手机号、身份证等敏感信息。
- 会话 Cookie 为 HttpOnly / SameSite；HTTPS 下加 Secure。
- 写操作要求同源 Origin、JSON 请求和会话 CSRF Token。
- 查询码包含随机密钥，数据库只保存其 SHA-256 摘要；请勿公开查询码。
- 顾客按会话隔离订单；跨设备查询或取消必须提供完整查询码。
- 公共页面明确说明：这是零元空气料理概念体验，不提供实体餐食、配送或线下席位。
